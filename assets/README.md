# Brand assets

Every icon, favicon, and splash image here (and the Android and web copies
under `apps/`) is generated by `ccez/brand/apply.sh <mark>` from a launcher
mark in `ccez/brand/marks/`. Edit the mark or the tile colours there and
re-run the script; don't edit these files by hand.

- `prod/`: release builds. `dev/`: development builds. `nightly/`: preview
  and nightly builds. Each variant is the same mark on its own tile colour.
- `app-icon.icon/`: Icon Composer project for iOS and macOS (tile colour
  plus the mark as one layer).

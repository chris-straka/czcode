# Morning brief

Once a day, the Morning brief sits at the top of **Home** (Needs you): a few
written lines on what happened since you last read one, on the machines the
feed's machine filter shows (every machine on the phone). Press **Done** and it
is gone on every device until tomorrow; the next one picks up from there.

- **Done:** what got finished, one line per project, written from the
  threads' final messages. On the web, a line opens that project's threads.
- **Failed or stopped:** failures grouped by cause, with the reason, and runs
  that were interrupted or cancelled, which are never counted as failures. A
  line can carry one action: **Retry** asks the threads to pick up where they
  left off, **Dismiss** archives them (with Undo).
- **Needs you:** how many Decisions are waiting (tap to open the first) and how
  many agents are waiting on an answer.
- **Machines:** a machine that is offline, overloaded, or short of disk or
  memory.

The brief never lists threads. Its lines are written by the same model that
writes thread titles; while it writes, or if it can't, each line shows a plain
count instead. It doesn't appear when there's nothing to report.
